**Task:** Discuss AI, machine learning, learning types and practical applications, and relate supervised image classification to WasteSort.

Artificial intelligence is the broad field of building systems that perform tasks such as image recognition and decision-making. Machine learning is one approach within AI: a model learns patterns from examples and uses them to make predictions. Deep learning uses multilayer neural networks within machine learning.

Three common learning types are supervised, unsupervised and reinforcement learning. Supervised learning uses examples with known target labels, such as emails labeled spam or not spam. Unsupervised learning finds patterns without target labels, such as grouping similar customers. Reinforcement learning uses reward feedback from actions, such as learning a game strategy.

WasteSort uses supervised multiclass image classification. Its training examples pair a waste photograph with one of six labels: cardboard, glass, metal, paper, plastic or trash. The model learns visual patterns and predicts a material category for a new single-item photo. This is classification because the answer is a category. A task that predicts a numerical quantity, such as travel time, is regression.

TrashNet provides the labeled images. Separate evaluation images help check whether the model can generalize beyond its training examples. Material prediction can support awareness, but bin instructions still require verified campus rules.
